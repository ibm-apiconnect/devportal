# IBM APIC Getting Started Module

## Overview

The IBM APIC Getting Started module provides interactive tutorials and guides for admin users of the IBM API Connect Developer Portal. It offers step-by-step instructions for common tasks through an off-canvas panel interface.

## Usage

Access tutorials from the admin toolbar by clicking on the "Getting Started" icon. The module provides tutorials for:

- Customizing Portal Theme

## Dependencies

- Drupal Core 9.x or higher
- jQuery
- Drupal AJAX Dialog
